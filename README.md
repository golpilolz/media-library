# golpilolz/media-library

Media library for Symfony forms: a form type opens a popup (Stimulus controller) to browse
folders and pick a file stored through Doctrine.

Requires Symfony 7.4+ / 8, Doctrine ORM, Twig, AssetMapper and StimulusBundle.

```bash
composer require golpilolz/media-library
```

Full documentation: [docs/index.md](docs/index.md). Flex recipe draft: [recipe/](recipe/README.md).
